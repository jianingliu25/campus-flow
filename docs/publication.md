# Early public checkpoint

This repository publishes the newly written Campus Flow reconstruction through M2.
It is an early preview, not a completed v1.0 or an original-course-code release.

Published under [jianingliu25/campus-flow](https://github.com/jianingliu25/campus-flow).
This is the permanent repository/share address; future work continues on main.

Included: authored backend/frontend, dependency locks, synthetic public fixtures,
schemas, tests, documentation, CI and screenshots of the reconstructed app using
fictional data. The new code/fixtures use MIT; dependencies retain their licenses.

Excluded: original course reports/slides/ZIP and images, old team code, private agent
sessions, real email, local SQL databases/indexes, credentials, .env, installed
dependencies and build outputs. No model weights are distributed.

The GitHub repository URL is the ongoing share link. Later milestones update this
repository's main branch and README; the complete release will use the same address.
The link shares source code and documentation, not a hosted live app. The preview
is launched locally using the README commands.

Current acceptance: M1 fixture preview and M2 local foundation. M3 local import,
M4 full UI, M5 IMAP/MCP, M6 SMOA, M7 recommendations, M8 evaluation and final M9
release remain the roadmap. No deployment or background automation is configured.
