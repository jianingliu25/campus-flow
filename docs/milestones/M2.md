# M2 acceptance record

Completed locally on 2026-10-12. This milestone establishes storage and permission
boundaries; real connectors, imported user data and model/index integration are
not enabled. No GitHub remote or release was created.

## Delivered

- 12 SQLAlchemy application tables and Alembic revision 0001, with private SQLite/WAL,
  foreign keys, UTC timestamp binding and idempotent startup migration.
- Composite source/workspace ownership constraints, per-source profiles/logs/documents,
  scoped repositories and transactional Email + VectorDocument + IndexOutbox updates.
- Ephemeral local sessions, HttpOnly/SameSite cookies, write CSRF, exact Origin,
  fetch-metadata checks, private no-store responses, body cap and redacted errors.
- Source metadata/activation/policy API scaffold and guarded email/event/index-status
  reads. Missing/stale selection and foreign identifiers are rejected.
- Versioned policies with default-off cloud, memory and implicit profile; source
  consent binds to provider URL/mode/model and is revoked on scope change.
- Separate LLM/embedding protocols; a gated compatible transport and local-only
  embedding boundary. Compatible cloud requests use public DNS-pinned IPs with
  original TLS SNI/Host, reject redirects and ignore environment proxies.
- Leased index outbox, atomic claims, replay/retry budget, lease-owner and revision/
  generation fencing. No index worker or model download starts automatically.
- migrate/db-status commands, updated locks/docs and browser settings startup status.

## Verification

Backend regression suite: **43 passed**, no warnings. Frontend typecheck/production
build and Python dependency consistency passed. npm reported 0 advisories when
updating its lock metadata; this is not a security audit.

Coverage includes:

- Migrated schema equals ORM metadata; empty test DB downgrade/re-upgrade and repeated
  startup migrations succeed; foreign keys and WAL are enabled.
- Failed transaction leaves no email, document or outbox row; duplicate writes are
  idempotent; changed content produces a new document/outbox version.
- Cross-source and cross-workspace reads/references fail; source switching rejects
  stale page headers; session source selection is independent.
- Missing session/CSRF, wrong Origin, cross-site/same-site metadata and oversized
  body are rejected. Input values, credentials and provider errors are not echoed.
- Defaults are local-only; conflicting policy revisions fail; scope changes revoke
  consent. Eight cloud-processing purposes cannot instantiate a provider while
  the global permission is disabled. Consent does not transfer across sources/models.
- A local Provider label cannot route to a remote endpoint. Cloud private DNS and
  redirects fail; mock requests preserve pinned IP, Host and TLS SNI.
- Remote embeddings and invalid vectors are rejected. All provider/embedding tests
  use mocks; no actual cloud call or embedding model download occurred.
- Parallel workers cannot claim the same active lease. Crash replay is idempotent,
  stale owners cannot ACK, new document versions cannot be falsely indexed, deletion
  state/generation changes block retrieval, and attempts are bounded with safe errors.
- Pending lease state survives closing/reopening SQLite and is recovered after expiry.

Actual server startup/migration and browser session bootstrap were verified.
Runtime contains 1 local workspace and **0 sources, 0 emails, 0 outbox tasks**;
the 30 visible emails remain independent fictional fixtures. The settings dialog
shows successful local-session startup. The demo's today query still works.
Nine recorded original reference hashes remain unchanged.

## Limits and next step

The index writer contract is tested with an in-memory double. Concrete FAISS,
model weights and file deletion are not implemented or counted as completed indexing.
Source APIs currently configure metadata only; no credentials, sync, imports or
LLM HTTP route are exposed. retain_body applies to subsequent writes; historical
cleanup, keyring and full data removal remain later milestones.
