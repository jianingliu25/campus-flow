# M9 — offline beta publication

The permanent share link remains https://github.com/jianingliu25/campus-flow .
Release target: `v0.9.0-offline-beta`, preserving the earlier immutable M2 preview.
This publishes the reconstruction engineering and offline acceptance results; it
does not claim real-account, learned-model, full semantic recommendation or
paper-scale acceptance.

Local acceptance uses 101 backend tests, frontend type checking/build, exact report
reproduction, and browser checks with authored fictional EML/MBOX records. Browser
checks cover source selection, the DDL shortcut with mail citation, explicit local
index processing and event editing form. Desktop 1440×900 and mobile 390×844 layouts
were checked for horizontal overflow. No production source was deleted through the
browser: deletion and late-worker rejection use temporary test databases.

Screenshots are reconstruction outputs with authored fictional mail only:
`docs/screenshots/m9-offline-desktop.png`, `m9-offline-mobile.png` and `m9-event-editor.png`.
Published files are audited before commit; runtime mail, credentials, private SQLite
and vector data, .env, dependencies, build outputs and original course material stay
outside Git. GitHub checks validate Windows and Ubuntu against the exact release commit.

Installation still requires downloading standard package dependencies. Demo and
rule-based operation are offline after setup; IMAP/MCP and model processing require
the explicitly selected services. The share link points to source and instructions,
not a hosted public mailbox app.
