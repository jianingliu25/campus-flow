## Runtime and limits

Verified on Windows, Python 3.11.9, Node 24.11.1, npm 11.6.2. Scripts are written
for macOS/Linux as well; those platforms have not been locally tested. GitHub Actions
defines Windows/Ubuntu checks but has not run because the repository is not published.

The app consumes only public fixtures. Its preset chat is not an LLM or SMOA.
Source connection, import, production storage, sessions/Origin protections,
indexing, actual recommendation scores, calendar writes and deletion are not yet implemented.
The readonly settings dialog explains these boundaries, rather than pretending to connect.
