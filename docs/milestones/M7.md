# M7 — local calendar, interests and durable search

Activities are candidates until explicitly joined. Membership is idempotent and
source-bound; no mailbox writes or activity registration occur. Calendar and
assistant busy-time tools use membership. Manual edits require an expected revision,
retain the original evidence with a manual-edit label, validate interval order,
and preserve date-only deadlines. Ambiguous/nonexistent local DST times require an
explicit offset. Later mail extraction preserves user edits and marks changed evidence.

Explicit interests are local and source-bound. Implicit interests require a policy
opt-in and retain only five fixed campus topics, not arbitrary query text. Signals
decay with exp(-age_days/30). At least five signals and effective weight three produce
a suggestion; the user must explicitly save the tag. `/profile/signals` DELETE clears
signals. QA history is separately opt-in; credential/contact-like queries are not
retained. These filters are best-effort and do not certify anonymization.

Recommendations use 0.3 * keyword similarity + 0.2 * time-distance freshness.
The planned 0.5 semantic term stays absent until a learned model is validated; scores
are not probabilities. Confirmed future activities include conflict warnings against
joined calendar events. No capacity numbers are guessed and no registration is sent.

Migration 0003 adds event revisions, membership and local vector tables. Vectors live
in the private SQLite database, recover after restart, and are protected by source,
generation, document-version and indexed-version filters. Indexing and rebuilding
are explicit manual actions; no model download happens. The default encoder is a
256-dimensional signed lexical hash, not learned semantic embedding. The optional
cached SentenceTransformer constructor uses local_files_only and trust_remote_code=False;
optional in-memory FAISS acceleration is implemented but neither optional runtime
has been accepted in this offline release. They are not required dependencies.

Export explicitly downloads selected-source mail, calendar, membership, profile
and QA history as private JSON. It excludes connector configuration and credentials.
Source deletion previews owned counts and manual edits, requires exact source ID,
commits a deletion barrier, stops sync at command boundaries, removes credentials,
and cascades all owned tables. A running sync may require retry; the source remains
blocked while waiting. Manual edits are deleted too: export first to preserve them.
Deletion attempts WAL truncation and compaction; a busy store reports pending.
Remote mail, OS backups and SSD remnants are outside this deletion guarantee.

Seven new regressions cover membership ownership, date-only edits and revision CAS,
durable search, generation fencing, late-worker rejection after deletion, scoped
export/profile, fixed-topic suggestions and contact redaction.
