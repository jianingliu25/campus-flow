# Security

M2 is a loopback-only local foundation with a fictional preview, not an audited application for real mail.
Do not expose it publicly or add real mail to tracked fixtures.

Real data, keys and raw logs must not be posted to public issues. A private security
reporting channel will be configured when the GitHub repository is published.
The project does not claim production security support or a response SLA yet.

Source isolation, local sessions, Origin/CSRF checks and processing consent now have
regression coverage. Credential keyring, connector permissions and removal of
historical/derived data remain later-milestone requirements. See docs/privacy.md.
